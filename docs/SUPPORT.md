# Support and data — ToDo POS

## Support

ToDo POS is offline-first. For help with the installed application, open
**Settings → About / Help → Support and data**, copy the diagnostic report, and
share it through the support channel supplied with your installer or Store
listing. The diagnostic report excludes customer names, product names, turnover,
barcodes and SMTP passwords.

## Export your data

The shop database remains on the device. To make a portable copy, use
**Settings → Backup / Restore** and create a full backup. To export permitted
reference tables, use **Settings → Database**. Before sharing a backup, remember
that it can contain local shop data.

## Delete local data

To remove local shop data from a device, first create and verify a backup if it
is needed for accounting or legal retention. Then uninstall the application and
delete the ToDo POS data folder that is shown in the diagnostic report. This
action is irreversible. No current ToDo POS cloud service receives or retains
the shop database.

## Privacy

The current app does not send sales, stock, price, barcode or customer data to
ToDo services. Future optional services must request consent before transmitting
data.
