# Microsoft Store listing — العربية

**الاسم:** ToDo POS  
**العنوان الفرعي:** نقطة بيع دون اتصال للتجارة والبقالة

ToDo POS هو تطبيق نقطة بيع يعمل دون اتصال للتجارة والبقالة. امسح أو ابحث عن
المنتجات، أكمل الأداء، شاهد الباقي، واحتفظ محلياً ببيانات المخزون والصندوق.

## المزايا
- بحث سريع بالباركود وواجهة كاشير مباشرة
- أداء نقدي وبالبطاقة ومختلط وبالدين
- تذكير بآخر عملية وطباعة الإيصال
- المنتجات والمخزون والموردون والزبناء والتقارير
- واجهة بالفرنسية والإنجليزية والعربية
- نسخ احتياطية محلية ونسخة تجريبية معزولة اختيارية

البيع والمخزون والأداء والمرتجعات وإغلاق الصندوق والطباعة والأجهزة المحلية
المدعومة تعمل دون إنترنت. ملفات البلدان هي إعدادات عرض وليست شهادة امتثال ضريبي.
