# الدعم والبيانات — ToDo POS

## الدعم
افتح **الإعدادات ← حول / مساعدة ← الدعم والبيانات**، وانسخ التشخيص المحلي
وشاركه عبر قناة الدعم المرفقة مع المثبت أو صفحة Store. يستثني التشخيص أسماء
الزبناء والمنتجات ورقم المعاملات والباركود وكلمات مرور SMTP.

## التصدير والحذف
استعمل **الإعدادات ← النسخ الاحتياطي / الاسترجاع** لإنشاء نسخة كاملة.
يمكن تصدير جداول البيانات المرجعية المسموح بها من
**الإعدادات ← قاعدة البيانات**. قبل الحذف المحلي، أنشئ وتحقق من نسخة احتياطية
إن كان الاحتفاظ المحاسبي ضرورياً، ثم احذف التطبيق ومجلد البيانات الظاهر في
التشخيص. الحذف غير قابل للتراجع.
