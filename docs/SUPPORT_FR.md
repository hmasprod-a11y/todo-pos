# Support et données — ToDo POS

## Support
Ouvrez **Paramètres → À propos / Aide → Support et données**, copiez le
diagnostic local et partagez-le via le canal fourni avec l’installateur ou la
fiche Store. Le diagnostic exclut les noms clients/produits, le chiffre
d’affaires, les codes-barres et les mots de passe SMTP.

## Exporter et supprimer
Utilisez **Paramètres → Backup / Restore** pour créer une sauvegarde complète.
Les tables de référence autorisées peuvent être exportées via
**Paramètres → Base de données**. Avant une suppression locale, créez et
vérifiez une sauvegarde si la conservation comptable est nécessaire, puis
désinstallez l’application et supprimez le dossier indiqué dans le diagnostic.
Cette suppression est irréversible.
