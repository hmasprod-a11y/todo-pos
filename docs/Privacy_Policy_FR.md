# Politique de confidentialité — ToDo POS

ToDo POS fonctionne d’abord hors ligne. Les ventes, stocks, prix, codes-barres
et fiches clients restent dans la base locale du magasin, sauf activation
explicite d’un futur service optionnel.

L’application actuelle ne transmet pas les données magasin, client, vente,
stock ou code-barres aux services ToDo. Les diagnostics excluent les noms des
clients et produits, le chiffre d’affaires, les codes-barres et les mots de
passe SMTP.

Les sauvegardes locales restent sous le contrôle de l’exploitant. Consultez la
page **Support et données** de l’application pour exporter ou supprimer les
données locales.
