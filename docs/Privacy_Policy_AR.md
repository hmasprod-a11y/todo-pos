# سياسة الخصوصية — ToDo POS

يعمل ToDo POS دون اتصال أولاً. تبقى المبيعات والمخزون والأسعار والباركود
وبيانات الزبناء في قاعدة بيانات المتجر المحلية، إلا عند تفعيل خدمة اختيارية
مستقبلاً بشكل صريح.

لا يرسل التطبيق الحالي بيانات المتجر أو الزبناء أو المبيعات أو المخزون أو
الباركود إلى خدمات ToDo. تستثني التشخيصات أسماء الزبناء والمنتجات ورقم
المعاملات والباركود وكلمات مرور SMTP.

تبقى النسخ الاحتياطية المحلية تحت تحكم المشغّل. راجع صفحة **الدعم والبيانات**
داخل التطبيق لتصدير البيانات المحلية أو حذفها.
