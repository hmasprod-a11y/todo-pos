# ToDo POS 1.1.0 — دليل سريع

هاد النسخة Windows كتخدم بدون Python من داخل الحزمة الجاهزة.

## أول تشغيل
1. شغّل ToDo.exe.
2. الدخول الأول: admin / PIN 1234.
3. بدّل PIN مباشرة.
4. دخل Paramètres واضبط اسم المحل، اللغة، الطابعات والنسخ الاحتياطي.

## أهم الوظائف
البيع، المرتجعات، المخزون، المشتريات، الموردون، الزبائن والدين، العروض، الوفاء، الجرد، أوامر الشراء، طلبات الزبائن وعروض الأسعار متوفرة داخل البرنامج.

البرنامج يدعم كذلك شاشة الزبون HDMI، afficheur série، ميزان série، RFID، طابعات متعددة حسب الاستعمال، طرق أداء قابلة للإضافة، وإرسال التذاكر والتقارير بالبريد.

## نقل البيانات
لنقل المحل إلى جهاز جديد استعمل Full Backup / Restore. لنقل الكاتالوغ فقط استعمل Export / Import produits مع معالجة تعارضات الباركود.
